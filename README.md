# 旧バージョンのサポート終了および公開停止について

本リポジトリで公開しているKB Gerber Viewer旧バージョンについて、サポートを終了し、2026年10月26日からWebサイトの公開を停止しています。

# 終了の理由

旧バージョンでは、Gerberデータの変換処理に外部CNCライブラリを使用しています。

しかし、当該ライブラリの更新が行われておらず、今後の保守・互換性・安全性の確保が困難になる可能性があるため、旧バージョンのサポート終了および公開停止を決定しました。

# 今後のご利用について

現在は新バージョンを公開しています。今後は新バージョンをご利用ください。

現行バージョン：
https://kb-gerber-viewer.pages.dev/

詳細な機能・対応形式・使用上の注意・ライセンスについては、以下をご確認ください。

https://kb-gerber-viewer.pages.dev/info.html

なお、公開停止後も、旧バージョンのソースコードを記録・参照用として本リポジトリに残す予定です。


# Gerber-Viewer
Web上でのガーバーデータ確認用の簡易ツール
## Important

本ビューアはGerberデータ確認用の補助ツールです。

スマートフォン等の端末向けには制作していないため、表示が崩れる可能性があります。

表示結果が実際のPCB製造結果と完全に一致することを保証するものではありません。
基板の製造・発注を行う場合は、元のCADデータや製造業者側のGerberチェック等も併用してください。

詳細な利用条件・注意事項・ライセンスについては
https://fuyu-31.github.io/Gerber-Viewer/info.html を参照してください。
