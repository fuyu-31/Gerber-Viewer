# Gerber-Viewer
Web上でのガーバーデータ確認用の簡易ツール
## Important

本ビューアはGerberデータ確認用の補助ツールです。

スマートフォン等の端末向けには制作していないため、表示が崩れる可能性があります。

表示結果が実際のPCB製造結果と完全に一致することを保証するものではありません。
基板の製造・発注を行う場合は、元のCADデータや製造業者側のGerberチェック等も併用してください。

詳細な利用条件・注意事項・ライセンスについては
https://kb2218-31.github.io/Gerber-Viewer/info.html を参照してください。
